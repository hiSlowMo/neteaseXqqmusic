NetEaseXQQMusic · 网易云 + QQ 音乐双平台插件，适用于 MyGo Music 0.1.20 及兼容后续版本。

此版本将项目和插件显示名统一为 **NetEaseXQQMusic**，仓库更名为 `hiSlowMo/neteaseXqqmusic`，同步更新插件首页、安装链接和发布包名称。

插件 ID 仍为 `music-fusion`，账号、混合歌单和旧版歌单导入格式沿用 0.1.0。音乐源请求、搜索和播放逻辑保持原样。

[在 MyGo Music 中安装](mygo-music://install-plugin?repo=hiSlowMo/neteaseXqqmusic) · [源码仓库](https://github.com/hiSlowMo/neteaseXqqmusic)

也可在 MyGo Music → Settings → Plugins → + 中填写仓库地址，或安装本 Release 的 `neteaseXqqmusic-0.1.1.zip`。安装 ZIP 包含完整源码、构建产物及 AGPL-3.0 和第三方许可。

验证：18 项核心离线测试及 JS 构建通过。0.1.0 已有用户确认实际登录测试可行；各类会员歌曲、长期续期及 provider 完整自动化回归尚未全面验证。暂停、缓冲和失败后跳歌策略由上游播放器控制。
