# v0.1.4 · App 扫码、音源分组与加载优化

## QQ 音乐 App 扫码

在插件设置“QQ 音乐扫码方式”填写 `qqmusic`，允许插件运行 ZIP 内置程序后点 Sign In，再使用 QQ 音乐 App 扫码。保留 `qq`（手机 QQ，默认）和 `wechat`（微信）。内置 macOS、Windows、Linux 的 arm64 / amd64 程序，使用时无需另行安装 Go、Node、辅助 App 或本地服务器；普通搜索播放及原扫码方式不会启动该程序。

## 音源分组与搜索

新增“按音源查看”和“搜索音源”设置，也可用 `qq: 反方向的钟`、`netease: 歌名` 临时指定平台。最近搜索已加载结果、最近播放和本地混合歌单可按平台分组，默认保留原始歌名、歌手与专辑信息，兼容外部歌词工具。公开 Track API 无独立徽标字段，全局混合搜索和队列仍不能添加自定义逐曲徽标。

## QQ 地址解析优化

相同歌曲与音质的并发播放地址请求现在合并处理，避免重复请求歌曲详情和 vkey。成功结果在同一账号会话代际内复用 30 秒，失败不缓存；登录、退出或代际变化后旧结果失效。签名 URL 仅保留在内存，不写磁盘，不降低音质或改变服务端权限。

此优化针对播放前的地址获取，不改变 CDN 下载方式。宿主 0.1.22 使用单个顺序 GET，未下载到快进目标时仍需等待，FLAC seek 还会进行多轮定位，因此本版本不保证消除后段拖动缓冲。进一步改善需要宿主支持 Range/按需范围下载。

完整 JavaScript 离线回归 60 项通过，ZIP 源码对应关系、六平台程序格式与执行位已核验；本机解包程序 IPC smoke 通过。App 扫码已有用户实测反馈；QQ/网易 CDN 同曲同音质对比、0.1.4 实机加载提速幅度及长期会话仍需验证。升级保留插件 ID `music-fusion`、账号和歌单数据，无需迁移旧定制应用。
