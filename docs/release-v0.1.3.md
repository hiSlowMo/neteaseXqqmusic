# v0.1.3 · QQ 音乐 App 扫码与音源分组

新增 QQ 音乐 App 扫码：在插件设置“QQ 音乐扫码方式”填写 `qqmusic`，并在 MyGo 中允许此插件运行内置程序，再点 Sign In。保留 `qq`（手机 QQ，默认）、`wechat`（微信）。安装 ZIP 已包含 macOS、Windows、Linux 的 arm64 / amd64 辅助程序，使用时无需安装 Go 或 Node。

新增“按音源查看”：将最近搜索已加载的结果、最近播放和本地混合歌单按网易云 / QQ 音乐分组。搜索可用 `qq: 反方向的钟`、`netease: 歌名` 临时指定平台，也可设置“搜索音源”。默认保留原始歌名，适合外部歌词工具。

上游暂未提供插件自定义逐曲音源徽标接口，全局混合搜索和播放队列仍无法单独加徽标；“歌名显示平台标签”仍是可选兼容方案，开启后可能影响外部歌词匹配。插件 ID、已有会话和歌单数据保持兼容。

34 项 JS 离线回归、Go race 测试与默认 vet 已通过；六平台程序构建和本机 IPC smoke 成功。额外 vendored vet/race 重复执行受本地权限限制，未计为额外通过。ZIP 已通过完整性、源码对应关系、六个平台格式和执行位核验，约 17.5 MB。QQ 音乐 App 的真实扫码确认、实际账号类型及原版宿主安装后的权限流程需要实测；不将合成测试视为实测成功。未读取或迁移本机真实账号。
